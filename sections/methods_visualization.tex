\subsection*{Biological visualization and figure provenance}
RNA maps (Fig.~\ref{fig:biological-explanations}; Supplementary Fig.~\ref{fig:s7}) were computed from the exact support/query unions of four frozen cases: coarse PBMC at 100 supports per class, fine PBMC at ten, and development and held-study cortex at ten, all with support draw zero. These comprise 320, 800, 7,769 and 7,163 query cells, respectively. Prediction labels and probabilities were recovered from the reference checkpoint's cached evaluation bundles, with matching observation identifiers, gene order and class order. Model predictions were not recomputed or changed by visualization.

For count inputs, rows were normalized to 10,000 counts and log1p-transformed; already processed cortex values were retained. Using Scanpy\cite{wolf2018scanpy}, a visualization-only Seurat-flavour selection retained up to 2,000 variable genes from the unlabelled support/query union. Genes were standardized and clipped at ten standard deviations. Principal-component analysis retained at most 50 components, followed by a 15-neighbour Euclidean graph and UMAP\cite{mcinnes2018umap} with minimum distance 0.3 and random seed 42. Coordinates were fitted once per case without annotation or prediction labels, then reused for reference, prediction, error, donor/study and gene overlays. Only query cells are displayed. These coordinates are RNA visualizations and were never used as classifier features.

The expression and detection matrices in Fig.~\ref{fig:biological-explanations}c summarize labelled supports; spatial expression overlays in Supplementary Fig.~\ref{fig:s7} show query values. Attribution panels use the original selected correctly classified query cells. Case-local attribution indices were joined to query barcodes through the original case manifests, with gene symbols restored in benchmark column order. Unexplained cells remain visibly distinct from zero-valued explanations. Expression and signed-attribution colors span the observed ranges independently; attribution colors are centered at zero. No cells or effect outliers were removed for visual appearance. The synthetic illustration uses one predetermined mean-program bank from the stated cellular configuration and displays all 16,384 generated cells; its anonymous genes and embedding are separate from the real-data maps. This illustration is not an additional realism or throughput measurement.

The supplementary sex/age display (Supplementary Fig.~\ref{fig:s6}) preserves the existing exploratory reference-checkpoint tasks. Sayed and Gerrits oligodendrocyte age targets use the study median among eligible units. Herring excitatory-neuron development uses four age classes ($<1$, 1--$<6$, 6--$<16$ and $\geq16$ years), three supports per class and twelve query persons; its AUC is macro one-versus-rest. Split-level means and ranges remain descriptive because units are reused. Recorded computational-cost panels (Supplementary Fig.~\ref{fig:s9}) distinguish adaptation optimizer compute, measured attribution time and extrapolated or estimated alternatives; they are not controlled end-to-end speed comparisons.
