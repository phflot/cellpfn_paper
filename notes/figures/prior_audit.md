# Simulator, ablation and phenotype figures

Implemented `scripts/figures_prior.py` and Supplementary Figures S1, S4, S5 and S6. Each has editable SVG/PDF, a 300-dpi PNG preview, a figure/panel manifest, source hashes, panel-level CSVs, an alignment report, a PDF collision report and a complete legend. No source repository or export was modified.

## Scientific contracts

- **S1:** calibration covers several biological effects while retaining important mismatches. Twelve selected primary statistics cover class effects, separability, donor effects, counts, detection and gene–gene structure. These are independently scaled distributions, not an arbitrary normalized realism score. Baseline/cellular summaries retain 5/25/50/75/95 percentiles; public summaries retain median and range. Real-reference units and synthetic bank/unit counts are recorded per panel. Class effects/separability exclude signed-covariance banks, leaving 96 of 128 cellular banks. The plotted real summaries exclude ROSMAP and overlap calibration/evaluation datasets. Fresh synthetic seeds do not establish independent real-data validation. A separately delivered fixed-seed synthetic UMAP supplies illustrative panels m,n; its new generation and boundaries are documented in `synthetic_illustration_audit.md` and do not change these quantitative summaries.
- **S4:** all three trained contrasts are shown for all genes, up to 8,192 HVGs and up to 2k HVGs, with twelve panel/budget combinations per contrast. The 108 paired means and 95% t intervals condition on twenty support draws. The failed original prespecified criterion is kept separate: PBMC donor-enumeration intervals have approximately 80% coverage; cortex uses 95% donor bootstrap within study. Inference-only rank-zero/off controls are distinct from separately trained diagonal/none arms. The one-support operator gate is zero, so small differences there reflect trained network differences. No displayed interval or control observation is clipped.
- **S5:** all ten candidates appear on axes separated by accuracy points, AUC and NLL. Candidate-specific endpoints and bases are retained. Exact original labels remain in the source CSV; visible abbreviated labels preserve their meaning. Routing-only candidates are not efficacy decisions; A8d remains not testable, not a drop. Task restriction replaces metadata tasks with 75/25 cell-type/donor identity tasks and excludes signed-covariance banks. CellPFN records 10,671,056 versus 6,386,352 cell exposures in the compared 4,000-update windows. Twenty-draw accuracy/NLL contrasts do not isolate task difficulty, because exposure and composition also change. The proxy task-stream replicates share one model seed.
- **S6:** only the reference checkpoint at update 96,000 is used. The original sex result is labelled GSM-aggregated rather than donor-resolved. Later sex plots include every ten-split AUC value at all four available budgets. Existing Herring/Sayed/Gerrits age tasks include all ten splits, with unit AUC separated from cell-level accuracy and NLL. Herring has **four** age classes (<1, 1–<6, 6–<16, ≥16 years), verified against `hashprompt/efast/tiers.py`; chance accuracy is 25%, not 33.3%. Herring uses macro one-versus-rest AUC. Sayed/Gerrits age targets are within-study median splits. Persons/GSM groups are explicitly distinguished, and no sex-gene attribution is invented.

## Numerical and rendering verification

- Recomputed all **132 plotted paired means and 95% t intervals** against the exported case-level values: 108 operator contrasts plus 24 task-mixture contrasts. Agreement to absolute tolerance `1e-10`.
- Runtime assertions verify candidate count (ten), sample counts, unique selections, exact task totals, ordered quantiles and the recorded strongest-marker anchor.
- All four render-time alignment gates pass with the skill's 1.5-point tolerance.
- All four PDFs pass the text audit with **minimum actual glyph size 6 pt**.
- All four PDFs pass the rendered collision audit with **zero FAIL and zero WARN findings** using isolated PyMuPDF dependencies. Contained fill overlays in S4/S5/S6 are intentional markers/legend/bar labels, visually inspected.
- Dimensions are 180 mm wide; heights are S1 184 mm, S4 182 mm, S5 189 mm and S6 153 mm.
- Full PNGs inspected. An initial S1 header overlap and S5 nested-heading overlap were fixed before final delivery. A clipped S4 footer and a control range extending below 80% were fixed. Updated plots retain all data.
- Standalone source validator cannot resolve centralized settings in `figures_common.py`. Concatenated-source validation verifies fonts/editable text; its remaining export flags are false positives from the dynamic `savefig` suffix loop. The requested SVG, PDF and PNG files exist and have recorded hashes. Its width warning misparses `180/25.4` as 180 inches; PDF dimensions and manifest are correct. A mathtext warning refers to the LaTeX legend string, not figure glyphs. The 300-dpi PNG is a preview; vector files are the publication artifacts.

## Reproduction and boundaries

Run `python scripts/figures_prior.py` from the manuscript repository, or select `--figure 1`, `4`, `5` or `6`. The plotting module uses the existing Python/Matplotlib common helper. If the installed figure skill is available, it also runs the alignment gate before export; scientific figures do not depend on the skill for data transformations.

Source-level provenance is available in each figure JSON and per-panel CSV. New biological validation, model-seed replications, sex-gene attribution, ROSMAP corrections and controlled simulator throughput remain outside these plots. Root integration owns manuscript figure numbering/cross-references and the final canonical PDF.
