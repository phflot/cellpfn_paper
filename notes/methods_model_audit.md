## Verification performed and limits

The drafted model/technical files contained no project-specific prior-version labels. These are static/source checks; they do not validate training outcomes or establish runtime numerical equivalence.

Runtime dependencies discovered in the default Python: pytest,NumPy,SciPy,pandas available; **torch,OmegaConf,anndata,TabICL unavailable**. No packages were installed. Neural tests were **inspected, not executed**. Relevant existing tests include:

- `tests/test_aligned_class_inducing_direct_pfn.py`: processed-mode no-renormalization;zero rows;row/gene/class equivariance;one-shot summary collapse;query cross-entropy-only objective;absence of analytic residual dependency.
- `tests/test_gene_gene_operator.py`: zero-initialization equality;one-shot gate;permutation properties;support/query contracts.
- `tests/test_gene_gene_operator_v2.py`:pooled-fit semantics;class-centered scalar with unequal support sizes;channel-squared/Mahalanobis identity;chunk independence;degenerate support;negative XOR and positive covariance controls;full-scale parameter count. The external gate-rule comparison requires a server file that is absent locally; the full-size memory/time test is not appropriate for a writing audit.
- `tests/test_gene_gene_operator_diag_v2.py`:same diagonal fit without low-rank factor;rank-zero equivalence;preserved rank context;one-shot gate;constant-gene masking;same parameter surface;zero-initialization parity.
- `tests/test_foundation_dataset_reuse.py`, `test_gene_gene_continuation.py`, `test_tabicl_cpt.py`, `test_tabicl_cpt_c2b.py`, `test_kumo_cpt.py`:relevant existing task/continuation/adaptation contracts, inspected through the implementation and file inventory rather than claimed executed.

No weights, biological matrices, remote training jobs or timing reruns were accessed. Full frozen checkpoint inference and environment reproduction remain future executable checks in an environment with the pinned dependencies. Existing tabular-model papers/software references support the external models; their absent third-party source is not silently described as locally audited.

## Final review corrections sent to integrator

These changes were communicated to the parent before its final compile; the integrating agent owns manuscript edits after the section split:

1. Write the summary-attention numerator as an inner product of two **affine** maps, `\langle f_q(\bar e_c+q_k),f_k(e_i)\rangle`, to include biases and remove ambiguous transpose placement.
2. Use `max(G_*,1)` in the mean variance-floor denominator, matching constant-support safeguards.
3. Specify natural-query allocation's10-cell/class floor, availability cap and rounding adjustment to fixed100C; this supplements the proportional allocation description.
4. Specify PCA support standardization, clipping at±10, component count min(100,N−1,H) and deterministic loading sign.
5. The admission nuisance comparison is **strictly less** than the analytic score minus0.025. “At least0.025lower” in a draft paraphrase should be replaced by the exact strict inequality when describing the rule.

Historical residual, role-slot, expert-routing and other alternatives remain identifiable in the repository but are not presented as components of the evaluated direct model. No new architectural experiment was proposed solely to rehabilitate such history. The already measured no/diagonal/full operator comparison directly addresses the joint-gene claim and is retained.
