# Quantitative table provenance

Tables 1–2 and Tables S1–S9 are generated by `scripts/build_tables.py` from the original, read-only `../paper_export_20261011/data` directory. `evidence/table_values.csv` records every numerical source selection used to produce the table cells and generated numerical prose, with source, exact filters, column, aggregation, scale, row count and full-precision value. Values use decimal half-up rounding after suppressing floating arithmetic noise below twelve decimal places. At the author’s request, values tied at the displayed precision receive the same bold treatment; this is a display rule, not a claim of numerical equality or statistical equivalence. Full-precision source values remain in the ledger. Repeated ledger entries deliberately retain each display's provenance.

`python scripts/check_tables.py` independently extracts ledger values using the existing fact-ledger reader, then checks that all generated TeX and ledger files match a fresh in-memory rendering. It does not edit files. `python scripts/build_tables.py --check` provides the rendering-only check; omitting `--check` regenerates the owned outputs. No exported files, experiments, model states or confidence intervals are regenerated.

## Narrative and design anchors

Design counts in captions (support budgets, draw counts, panel counts, training windows and task mixtures) are supported by the same selected records and enforced selection sizes. Supplemental table numbers and model-version names are identifiers, not outcome estimates. Additional numerical context uses these anchors:

- 40,000 adaptation tasks, 10,000 replay tasks and 2,500 updates: `fig3__arms`, the `training_data`, `simulated_tasks` and `updates` fields for `c2b`, `k2b_s`, `k2b_l`. The published **35 million** TabICLv2 pretraining datasets are an external-source claim cited to `qu2026tabiclv2`, not falsely presented as a locally verified export value.
- Operator harm contribution: `fig6__operator_n3_test_wide`, coarse-PBMC B10, `A_operator_off`; the complete frozen decision and effective interval coverage are retained in that row.
- Proxy guard and keep/noise values: `supp_prior_ablation__outcomes`, `supp_prior_ablation__thresholds`, `supp_prior_ablation__replicates`; mechanism headroom and gap shrinkage additionally appear as ledgered S5 table cells.
- Prior v2.2-B's 16.7% share: `fig1__facts`, `lineage.share_of_tasks_on_v22B_at_96000`; task-mixture cell-exposure ratio follows the two ledgered means in S6 and is only approximate.
- Cortex gene widths: `supp_stored_zeros__facts`, `zebra.genes_processed_panel` and `zebra.genes_counts_panel`. Support-identity changes are documented by `supp_stored_zeros__support_replacement`.
- Stage-0 stored-zero intervals: `DATA_DICTIONARY.md`, description of `supp_stored_zeros__facts` explicitly identifies 95% t intervals over ten draws. They are copied from the current export rather than newly fit.
- ROSMAP selection reuses the exact registered R38 selection, including sex matching, donor supports, pool, task and endpoint. Its interval is the exported corrected repeated-split 95% interval, not a naive interval over donors or cells.
